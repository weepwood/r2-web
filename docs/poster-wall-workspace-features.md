# PosterWall 功能完善：图片定位、顺序导航与视角书签

> 实施范围：r2-web / PR #8。本文描述已提交的功能，未声称提供全 Bucket 搜索或服务端收藏同步。

## 1. 当前已实现的交互

| 功能 | UI 入口 | 键盘 |
| --- | --- | --- |
| 查找图片 | 展示墙右上角放大镜 | `/` 或 `Ctrl/⌘ + F` |
| 搜索结果跳转 | 查找面板的前进/后退按钮 | 搜索框中按 `Enter` / `Shift+Enter` |
| 依次聚焦图片 | 直接单击图片 | `PageDown` / `PageUp` |
| 保存当前视角 | 底部书签加号图标 | — |
| 恢复已存视角 | 底部书签勾号图标 | — |
| 关闭查找面板 | 再次点击放大镜 | `Escape` |
| 收起当前图片 | 展开后的“收起”操作 | `Escape` |
| 退出展示墙 | 右上角关闭按钮 | 未选中图片且未打开搜索时按 `Escape` |

查找面板只根据 `PosterWall.#items` 的已加载图片 Key 搜索文件名和路径，**不会额外列出整个 R2 Bucket**。支持大小写不敏感的字符匹配和 NFKC 字符规范化（包含中文文件名及全角英文）。输入不触发网络请求，只有用户按 Enter 或点击结果导航按钮时才展开、移动到目标图片。

查找结果在当前加载列表变化时更新。无结果时保留搜索框与说明，不清空原始图库，也不影响滚轮和普通画布缩放。

## 2. 视角书签

- 每个 `R2 accountId + bucket + currentPrefix` 生成独立的本地存储键。不同账户/桶/目录互不共享。
- 书签只保存 `version`、画布世界坐标中心 `centerX/centerY` 和缩放 `scale`，**不保存 R2 Secret Access Key、签名 URL、图片文件列表或原始图像数据**。
- 只有点击“保存当前视角”时才写入浏览器 `localStorage`，不会在每一次滚动时自动写入。
- 点击“恢复已保存视角”后，以 430ms 相机缓动返回保存时的世界坐标中心。窗口宽高不同仍能保持相同的空间定位。
- 无有效书签时恢复按钮不可点击；已存在非法/损坏/旧版本的书签时安全忽略，避免相机出现 `NaN`、异常倍率或远距离跳变。
- 如果保存的是图片展开时的镜头位置，书签仍只存视角而不保存临时选中与局部重排状态。
- 清除站点本地存储会同时清除这些书签；目前没有云端同步、分享或书签管理列表。

## 3. 性能与 UI 限制

- 搜索只在输入事件或当前已加载文件集变化时扫描已加载 Key，不在相机每帧执行；
- 镜头平移仍然保持 PR #8 的 transform 快速路径、视口裁剪以及有限的图片加载并发；
- 手机端底部快捷按钮与缩放 HUD 分层排列，展开图像的浮动操作条避让底部按钮区；
- 控件包含无障碍名称、快捷键与即时状态反馈，尊重 `prefers-reduced-motion`；
- 未修改 R2 操作权限、原图下载方式或上传数据结构。

## 4. 回归测试

- `tests/poster-wall-workspace.test.js`：目录书签隔离、图像 Key 搜索、跨分辨率相机恢复、非法书签过滤；
- `tests/browser-smoke.mjs`：Chromium 真实页面模拟 R2 图片，查找图片并展开、PageUp/PageDown 顺序导航、保存/恢复、关闭后重新打开仍可恢复；
- 原有 240 张模拟图片的 48 帧滚轮结构性能回归继续运行，保证新增功能没有把搜索放进高频相机计算路径。

## 5. 后续能力

可按需要增加可管理的多视角收藏列表、单图片快捷收藏、文件元数据筛选、全 Bucket 索引搜索或将 PosterWall 视角导出为可分享的**无凭据**场景描述。这些目前尚未实现，且全 Bucket 搜索需要独立的索引方案。
