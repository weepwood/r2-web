# R2 Web — PosterWall 动效与 UI 精修审查（2026-11）

## 结论：不是缺少装饰，而是缺少注意力层级

当前实现已具有无限画布、几何拼贴、缩略图策略、图片展开、文件详情等能力。但之前 **每张磁贴的目录标签、强渐变、固定大标题、持续骨架闪动、常驻浮动按钮** 会争夺用户注意力。文件管理器的图库卡片还叠加边框、阴影和悬停上浮，使图片墙与工作台都显得过度「组件化」。

这轮采用 **图片是内容，控件只在必要时出现** 的原则：安静默认态、明确交互态、短促可中断反馈、低运动成本、键盘可触达。

## 设计研究与取舍

## 动效原则和实际参数

### 1. 图片焦点展开

- 保留原有 `focusReflow` 布局，使用 WAAPI FLIP 把磁贴移动和缩放保持在合成器适合处理的 `transform` 上。
- 旧动画先读取当前视觉边界，再取消并从当前位置运行下一次动画，避免反复点击时突然跳回起点。
- 弹簧时长由 **630ms 缩短到 480ms**，采用快速阻尼且仅有极轻的超调；强调空间关系，不强调弹跳。
- 背景图片仍可识别，不再整个墙面几乎变黑。

### 2. 相机运动

- 真实鼠标移动、滚轮和捏合依然是直接操控，**不叠加人为惯性**。
- 工具栏缩放采用 **235ms** ease-out，重置视角 **320ms**；任意新的控制或拖拽会打断之前的动画。
- 普通滚轮灵敏度由 `0.0019` 改为 `0.00125`，触控板放大手势使用 `0.0022`，减少突兀大幅缩放。
- 相机只改父画布 `transform`；磁贴在几何坐标没有变化时不再重复写入 left/top/width/height。

### 3. 键盘、低动态与触控

- 展示墙打开时，背景操作区设为 `inert`，防止键盘 Tab 跳回隐藏在墙后的文件操作控件；退出时恢复原状态。
- 展示墙级别捕获 Esc、方向键、`+`、`-`、`0`，即使焦点落在右上角或底部浮动按钮上也可操作。
- `prefers-reduced-motion` 对 CSS 与 WAAPI 均生效；用户系统设置动态变化为减少运动时，也立即停止当前动画。
- 触控屏保留更易识别的控制按钮，而非为了极简将退出入口隐藏。

## 性能与安全边界

- 没有更改 R2 S3 鉴权、签名 URL、Bucket 配置或原图加载策略。
- 默认缩略图仍使用 Cloudflare Images 转换优先、严格模式无原图回退，并受 4 个并发请求和视口裁剪限制。
- 不生成私有文件的公开 URL，也不会为了显示文件详情或展开图片就读取私有原图。
- 批量图片文件加载仍由当前分页的文件列表驱动；不会自动一次请求整个存储桶。

## 焦点展开碰撞修复（代码复核增补）

旧算法每个邻居只做一次单向位移，没有核对它和**其他已移位磁贴**的相交关系；在密集的固定几何模板中，展开任意磁贴都可能出现新重叠。

本轮把 `focusReflow` 改为**固定主磁贴 + 远处优先固定 + 邻近磁贴最近空位搜索**。它以 6px 为最低安全间距，优先让较远磁贴留在原位；只有可能发生相交的局部磁贴才寻找合法空位。搜索限定候选数，极端密集情况下使用无碰撞兜底位置而不是让图片重叠。缩放比例也适度收敛，使展开聚焦更稳健。

新增 `poster-wall.test.js` 中的几何回归：对多张图片分别作为焦点执行展开，在所有两两磁贴之间检查 6px 间距并验证结果确定性。**这些是几何与源码级测试，不代表已完成真实图像的视觉验收。**

## 第七轮：细节交互与真实加载优化（继续优化）

本轮重点修复了三处真实使用上的边界问题，而不增加装饰元素：

### 手势与开场位置

- 单指/鼠标按下后，在累计移动 **7px** 以前保持点击判定，避免微小抖动立即移动画布。越过阈值后才开始平移，并明确取消点击目标。
- 双指捏合会永久标记当前手势已使用多点触控；放开其中一指后，剩余手指的起始位置重新基准化，避免捏合结束时产生大幅突跳或触发磁贴。
- 进入只有一两张图片的目录时，根据前一组实际磁贴的边界居中并适配，而不是假设画布永远存在固定 1080px 宽的初始作品区。
- 跨过 760px 响应式断点时，三列/两列几何模板重排仍然保持当前焦点或可见中心磁贴的**屏幕中心锚点**；ResizeObserver 只在实际尺寸变化时更新。

### 缩略图按需升级

- 新增屏幕可见区域优先的图片任务排序：可见图片优先，超出视口的 overscan 图片后加载；同时仍然最多 4 个网络任务。
- 快速连续缩放并不在每个动画帧新建图片请求。缩放停顿 **230ms** 后，才判断可见磁贴是否需要从 160px 升到 320/480/640px。
- 升级采取**双缓冲**：旧图继续显示，新缩略图下载成功后才替换 DOM 图片节点。失败时保留旧图，并记录失败档位避免同一档位无限重试。
- **不因缩放而请求原图**：仅首次请求小图失败、且用户当前处于允许原图回退的智能模式时，才保留兼容策略；已经显示小图后的清晰度升级失败不会转而下载完整原图。
- 私有桶的严格省流量策略继续只显示占位，不会借此绕过 Bucket 访问规则或把敏感数据存入额外的浏览器持久缓存。
- 根据缩放比例切换总览/标准/细节显示层级；总览时弱化非聚焦标题，鼠标悬停、键盘焦点和展开态仍显示文本。

### 验证范围

- `tests/poster-wall-gestures-thumbnails.test.js` 检查新手势阈值、双指误触防护、首页位置计算、CDN 并发/优先策略、缩放升级、原图回退边界和总览样式。
- `tests/poster-wall.test.js` 增加跨断点的锚点保持纯几何测试。
- 此类检查涵盖了几何函数和静态关键路径；它们**不构成实际触摸屏的端到端测试**。真实 R2 Bucket 的长目录、多种图片格式、CDN 缓存和移动端实际手感仍需预览环境手工验收。
