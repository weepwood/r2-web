# R2 Web UI Refresh（2026-11-07）

## 设计目标

把原有简洁的原生文件管理器整理为更清晰的存储工作台，同时保留 Cloudflare 橙色标识、零构建架构和原有交互。

- **应用导航**：扩大品牌识别区，保持 Bucket 选择器、设置和退出入口位置稳定。
- **文件工作区**：细化页面、卡片、列表的背景与边框层次，增强文件类型、名称和元数据的可读性。
- **操作工具栏**：强调上传主操作，整合排序与视图切换状态，改进路径导航的窄屏表现。
- **设置界面**：桌面版使用左侧纵向页签，平板及手机恢复顶部横向滚动页签。
- **空状态与上传队列**：提供明确操作入口与独立信息层级。
- **无障碍与兼容性**：保留焦点轮廓，兼顾高触控输入与减少动态效果偏好。

## 实现方式

样式集中在 `src/css/refinements.css`，从 `src/style.css` 在原有样式之后引入。只更改 `src/index.html` 中顶部品牌及工具栏的结构类名，保留原有 ID、`topbar-title` 以及 `.topbar > .flex.items-center` 节点，以便现有多 Bucket 管理器继续注入选择控件。

未修改 R2 API、签名、配置持久化、Bucket 切换、上传、删除、复制、移动或文件预览逻辑。

## 回归检查

自动化：`pnpm test`、`pnpm typecheck`（如果依赖已经安装）。

手工（连接真实 R2 环境之后）：

1. 桌面宽度 1440 / 1024：检查网格、列表、排序、全选和批量操作。
2. 移动宽度 390 / 320：检查 Bucket 长名称、工具栏换行、文件列表和底部批量操作条。
3. 浅色 / 深色、紧凑 / 标准 / 宽松，以及系统减少动态效果设置。
4. 设置的五个页签切换、输入焦点、保存和关闭。
5. 空目录、缩略图加载、上传面板、预览和提示消息。

本 PR 不包含真实 Cloudflare R2 凭据，也不自动对远端存储桶执行更改。

## 第二轮：文件筛选与批量交互

- 工具栏增加当前目录本地文件名筛选（含 `/` 快捷键、清除按钮、无匹配结果状态）。
- 不调用额外 R2 API；浏览器端仅匹配已经加载的当前目录文件与文件夹名称。
- 输入筛选条件时清空已有批量选中，避免隐藏的项目继续参与批量删除、移动和复制。
- 全选仅包括当前可见的卡片，筛选结果显示“显示 M / N 项”。
- 切换目录时清除筛选，刷新时保留搜索条件。
- 国际化新增简体中文、繁体中文、英文、日文的筛选提示与空状态。

## 键盘与辅助访问

- 设置弹窗各页签以 `aria-controls` / `aria-labelledby` 关联面板。
- 桌面和移动端支持方向键、Home、End 切换设置页签，采用 roving tabindex。
- 避免反复打开设置时重复注册页签点击监听器。
- 仅图标按钮补全随当前语言更新的 `aria-label`；触控环境适度放大关键操作热区。

## 第三轮：文件预览与上传队列

- 预览弹窗新增「上一个 / 下一个」按钮、当前位置标记，支持在图片/文本预览中使用左右方向键。
- 预览范围限制为当前已加载、未被本地筛选隐藏且支持预览的文件；音频/视频预览保留原生键盘控制，避免覆盖媒体快进快退操作。
- 切换预览目标和关闭弹窗时废弃旧的异步请求结果，防止 HEAD/预签名/文本内容旧响应覆盖当前文件。
- 新增加载和错误提示，文件元数据改用 textContent 渲染，避免将不可信 Content-Type 拼进 HTML。
- 上传任务面板加入整体完成比率与百分数、可折叠列表、成功或部分失败的明确状态；修复请求异常后进度条继续循环的问题。
- 本次只在上传任务 UI 中显示进度，百分比代表**已完成的文件数占比**，不是字节传输进度或可中断上传。
- 后续手工回归重点：文件快速切换、媒体播放器按键、320px 手机、上传失败与断网时的面板状态。

## 代码审查修复（合并前）

- 修复文件预览弹窗快速关闭并重新打开时，上一轮异步 `close` 事件可能清除当前预览状态的问题。
- 修复多个上传批次交错执行时，上一批的标题/百分比/最终状态可能污染当前批次的问题；任务标识添加批次代次，旧任务仍执行但不更新新批次面板。
- 注意：上传面板只展示**最近启动的一批**，并不是全局跨批次累计队列。
- 补充静态回归检查；R2 实际账号的上传/签名/预览回归尚未现场执行。
