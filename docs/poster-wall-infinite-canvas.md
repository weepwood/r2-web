# PosterWall · Infinite Canvas Mosaic 展示页

> 参考 [Folia PosterWall](https://github.com/chthollyphile/folia-major/blob/main/src/components/app/lattice/PosterWall.tsx) 的沉浸式视觉/交互语言。布局、手势、重排和图像加载代码均独立实现，没有复制该项目受 AGPL-3.0 约束的实现代码。

## 访问入口

在 R2 Web 中连接存储桶，进入任意包含图片的文件夹，然后在工具栏网格 / 列表 / 画廊旁点击「沉浸式展示墙」按钮。展示墙是一个独立覆盖整个工作区的视图，关闭后回到原文件列表，原来的排序和文件操作不受影响。

只会展示当前目录**已加载的图片**；如果 R2 目录有更多对象，可以点击展示墙的「加载更多图片」明确获取下一页。不会自动遍历整个 Bucket。

## 布局与视觉

- 背景 `#070707`，文字 `#f7f4ee`，直角磁贴，6px 间距，`object-fit: cover` 裁剪。
- 3 套独立创作的 **6 × 4 单元无重叠模板**，包含不同跨度的长方形与正方形磁贴。模板在二维宏块中重复拼合，**不是** masonry/瀑布流、动态均分卡片或随机位置。
- `src/js/poster-wall-layout.js` 提供纯几何函数 `buildWallLayout`、`cameraBounds`、`zoomAt`、`focusReflow`，可单元测试。
- 每张图片有深色渐变、大字号标题与目录副标题；无大面积玻璃拟态卡片。深色半透明圆形按钮仅出现在画布控制区域。
- 相机不限制到内容边界，因此可在无限坐标平面自由平移；图像对象是有限的，由用户当前已加载的 R2 文件组成。这里的「无限画布」不表示无限图片资源。

## 手势与键盘

| 输入 | 行为 |
| --- | --- |
| 鼠标 / 单指拖动 | 平移画布 |
| 鼠标滚轮 | 围绕鼠标光标缩放 |
| 双指捏合 | 围绕双指中心缩放并平移 |
| Shift + 滚轮 | 平移画布 |
| 点击 / Enter / Space 聚焦磁贴 | 原位展开，再次点击收起 |
| 方向键 | 平移画布；Shift 加速 |
| `+` / `-` | 缩放 |
| `0` / `Home` | 重置相机 |
| `Esc` | 先收起磁贴，再退出展示墙 |
| Tab | 顺序聚焦视口、可见磁贴和控制按钮 |

缩放范围是 0.35～2.8 倍。布局在当前视口 + 420 屏幕像素的扩展边界内才创建 DOM，离开视口的磁贴会释放图片任务并移除节点。最多四张图片同时加载。

## 点击动画与内存管理

选中磁贴后，`focusReflow` 会扩大该磁贴，并将与新矩形重叠的邻居推向最短可行方向。远处磁贴不动。背景 tile 视觉暗化。动画采用 FLIP + WAAPI 自定义阻尼关键帧；交互中断时先捕获当前屏幕坐标，取消旧动画，从当前位置继续，不会把磁贴瞬间跳回原起点。

当用户启用 `prefers-reduced-motion: reduce`，跳过 WAAPI 布局过渡并关闭 CSS 动画/渐变过渡。

图片下载遵守主应用的三档缩略图策略：Cloudflare Images 可在公开自定义域名上返回真正的小图；严格省流量模式不回退到原图；私有 R2 在没有受保护的缩略图服务时严格模式显示占位图。**点击展开本身不会请求原图。** 只有点击「查看原图」才打开主应用原有的按需预览组件。

- `src/js/poster-wall-layout.js`：固定模板、空间变换、局部焦点重排
- `src/js/poster-wall.js`：相机、虚拟可见节点、缩略图队列、手势、WAAPI 动画、键盘
- `src/css/poster-wall.css`：完全独立的深色图片墙视觉层

- `src/index.html` / `src/js/app.js`：入口和与主应用的预览/分页集成

- `tests/poster-wall.test.js`：模板 24 单元完整覆盖、间距、缩放锚点、焦点重排、源码安全/无障碍测试

## 实地验收建议

1. 使用公开且开启 Cloudflare Images Transformations 的 Bucket，确认展示墙的小图来自 `/cdn-cgi/image/`，点击磁贴展开**不会**触发原图请求，点击「查看原图」才发出原图 GET。
2. 使用私有 Bucket 的严格模式，列表与墙面不可自动请求原图，点击「查看原图」则可按现有鉴权流程预览。
3. 在 320 / 768 / 1440px 视口，检查不同模板、流畅平移、锚点缩放、双指捏合与视觉裁剪。
4. 展开磁贴期间反复点击其他磁贴、拖动及缩放，确认布局跳变和旧动画冲突不存在。
5. 只用键盘完成打开、聚焦、展开、查看原图、退出操作；系统降低动态效果后重新检查。
6. 在 R2 大目录内明确点「加载更多图片」检查列表分页与图片墙同步。

自动化测试不等价于已在真实 R2 / Cloudflare Zone 中完成所有浏览器和网络环境验证。
